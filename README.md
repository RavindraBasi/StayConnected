Problem Statement:-
    In today's connected world, sudden loss of communication can cause significant anxiety. A critically low or dead phone battery often makes users unreachable without warning, leaving family members and friends uncertain whether the situation is harmless or potentially dangerous. Existing communication systems fail to provide advance context before a device goes offline. A solution is needed to proactively inform trusted contacts about an impending communication loss, enabling them to make informed decisions without making false assumptions about the user's safety.
